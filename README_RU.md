# Bybit Read Only MCP для ChatGPT

Это безопасная первая версия пользовательского приложения ChatGPT:

- только публичные рыночные данные Bybit;
- API-ключ не нужен;
- нет покупки, продажи, создания/изменения/отмены ордеров;
- нет доступа к балансу и позициям;
- транспорт: Streamable HTTP;
- адрес после размещения: `https://ВАШ-ДОМЕН/mcp`.

## Инструменты

- `get_ticker` — текущая цена и тикер;
- `get_klines` — свечи OHLCV;
- `get_orderbook` — стакан;
- `get_funding_history` — история funding;
- `get_open_interest` — открытый интерес;
- `server_status` — проверка связи.

## Размещение на Render с телефона

1. Создайте новый пустой репозиторий на GitHub.
2. Загрузите в него файлы из этой папки.
3. В Render выберите **New → Blueprint** и подключите репозиторий.
4. Render прочитает `render.yaml` и создаст веб-сервис.
5. Дождитесь статуса **Live**.
6. Скопируйте URL сервиса, например:
   `https://bybit-readonly-mcp.onrender.com`
7. MCP-адрес будет:
   `https://bybit-readonly-mcp.onrender.com/mcp`

На бесплатном тарифе первый запрос после простоя может выполняться дольше.

## Что заполнить в ChatGPT

- **Название:** `Bybit Read Only`
- **Описание:** `Публичные цены, свечи, стакан, funding и открытый интерес Bybit. Только чтение.`
- **Подключение:** `URL-адрес сервера`
- **URL:** `https://ВАШ-ДОМЕН/mcp`
- **Аутентификация:** `Без авторизации`
- Пропустите значок.
- Нажмите продолжить/сканировать инструменты, затем создайте приложение.

## Проверка

После подключения спросите:

- `@Bybit Read Only покажи цену BTCUSDT`
- `@Bybit Read Only покажи 50 свечей LABUSDT на 15 минутах`
- `@Bybit Read Only покажи стакан ETHUSDT`
- `@Bybit Read Only покажи открытый интерес BTCUSDT за 5 минут`

## Важная безопасность

Не добавляйте API Key или Secret в код и не отправляйте их в чат.

Для второй версии с балансом и позициями нужен отдельный защищённый сервер и авторизация. Торговые команды следует добавлять только отдельно и с обязательным подтверждением каждого действия.
